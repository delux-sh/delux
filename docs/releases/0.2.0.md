# Delux 0.2.0

Create, monitor, attach to and explicitly end tmux sessions across your computers, without a remote Delux service.

## What's new

- **New session:** press `n` in the picker to choose a name, directory and optional command, then create and attach. Creation never replaces an existing session and never automatically retries after an uncertain result.
- **Add computer:** press `a` to save an SSH destination or alias. Existing mappings are preserved; adding probes in the background without opening interactive SSH prompts. Available when using the configured computer list, not `--local` or explicit `--host` overrides.
- **Agent status:** see working, waiting, done and error states in the picker and inventory. Native OSC 7501 reporting is used when supported by tmux; `delux agents install` configures detected Claude Code, Codex, Gemini CLI, OpenCode, Pi and OMP hooks. Install hooks on each computer where agents run. Codex requires trusting the hooks through `/hooks`; restart existing agent sessions.
- **End session:** press `x` with the list focused. The confirmation identifies the session and computer and defaults to Cancel. Ending closes all windows and panes in that session and can terminate programs or agents, losing unsaved work. Delux checks the captured session/server identity and never retries automatically or selects a replacement by name. Detach and quit still leave sessions running.
- **iPhone companion source:** the native SwiftUI/SwiftTerm app connects directly over SSH, shows sessions and agent status, and supports terminals, creation and confirmed termination. This CLI release does not distribute an iOS binary; TestFlight and App Store distribution are not yet available.

## Install or upgrade

After the v0.2.0 tap update is published:

```sh
brew update
brew upgrade delux-sh/tap/delux
```

For a new installation, use `brew install delux-sh/tap/delux`. Homebrew installs tmux and, on Linux, OpenSSH. macOS uses its system OpenSSH. Check `command -v delux` if an older manual installation shadows the Homebrew binary.

Release archives cover macOS Apple Silicon and Intel, and Linux ARM64 and x86_64. Download your platform's `delux-0.2.0-<target>.tar.gz` and `SHA256SUMS` from this release, and verify its SHA-256 before extracting. Source installation is available with `cargo install --path . --locked` from the [tagged source](https://github.com/delux-sh/delux/tree/v0.2.0).

## Compatibility and limits

- Uses the default tmux server only, not custom `tmux -L` or `-S` servers. Requires tmux 3.2+; native OSC 7501 agent status requires a supporting tmux version newer than 3.8. Hooks work with older supported versions.
- Remote access requires OpenSSH and remote `base64`/`tr` available to noninteractive `/bin/sh`. Tailscale is optional.
- Native agent status takes precedence over hooks. A reported working state becomes stale after ten minutes without a newer status or pane output; screen-output age alone is not agent status.
- The embedded terminal supports keyboard input and wheel scrolling, not mouse clicks/dragging, terminal graphics or advanced keyboard protocols. Use `delux attach` for your terminal's full behavior.
- iPhone builds require separate signing. Desktop SSH aliases, ProxyJump, imported private keys, keyboard-interactive/MFA and automatic tailnet discovery are not supported in the app. Use the separate Tailscale iOS app when needed. Physical-device testing remains outstanding.
