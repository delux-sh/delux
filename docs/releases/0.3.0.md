# Delux 0.3.0

Find sessions that need you, connect over the local network when available, and set up agent reporting without disturbing running terminals.

## What's new

- **Attention in Browse:** waiting sessions appear above pinned sessions, with numbered `1`–`9` shortcuts. The section disappears when empty. Numbers open sessions only with sidebar focus; terminal, filter and form input are unaffected. Press `v` for the complete Attention view, separate errors and reporting coverage.
- **Live cross-computer status:** both Browse and Attention refresh remote status without replacing an attached terminal. Missing or unavailable reporting is not treated as an all-clear. Status and pin markers now occupy separate columns.
- **LAN-first connectivity:** discover advertised Bonjour/mDNS SSH services and configure explicit LAN routes for known computers. Unambiguous matches avoid duplicate computers, alternate routes preserve SSH trust, and failed mutations are never replayed. Tailscale remains optional.
- **Guided reporting setup:** press `s` in Attention to inspect native tmux support, running agents and profiles. Review the exact computer and files before confirming installation. Bundled Pi/OMP extensions and OpenCode plugins can be installed over SSH without a remote Delux binary; other built-in hooks require a compatible remote installer. Setup does not restart agents or replace terminals.
- **OMP profiles:** the installer resolves `OMP_PROFILE` before `PI_PROFILE`, and guided setup also inspects the running process's `--profile` argument. Named profiles receive their own extension instead of accidentally installing into the default profile.
- **iPhone companion source:** Attention, guided reporting setup, nearby-computer pairing, trusted LAN-first connection fallback and terminal-layout improvements. This release does not distribute an iOS binary.

## Install or upgrade

After the v0.3.0 tap update is published:

```sh
brew update
brew upgrade delux-sh/tap/delux
```

For a new installation, use `brew install delux-sh/tap/delux`. Homebrew installs tmux and, on Linux, OpenSSH. macOS uses its system OpenSSH. Check `command -v delux` if an older manual installation shadows Homebrew.

Archives cover macOS Apple Silicon and Intel, and Linux ARM64 and x86_64. Download `delux-0.3.0-<target>.tar.gz` and `SHA256SUMS`, and verify the archive's SHA-256 before extracting. Source installation is available with `cargo install --path . --locked` from the [tagged source](https://github.com/delux-sh/delux/tree/v0.3.0).

## Compatibility and limits

- Uses the default tmux server, not custom `tmux -L` or `-S` servers. Requires tmux 3.2+; native OSC 7501 status needs a supporting tmux version newer than 3.8 and an agent that emits it. Adapters support older tmux versions.
- Optional guided setup requires Python 3 on the inspected computer. Normal browsing does not. Installation refuses unsafe or ambiguous paths and stale proposals; uncertain installations are not retried automatically.
- Installing an adapter is not proof of reporting. Restart or resume the agent yourself at a safe point; questions already open before the adapter loaded are not replayed. Codex hooks also require `/hooks` trust.
- LAN discovery depends on advertised SSH services or explicit configuration; it is not a scan of every address on the subnet. Unknown or changed host keys are not trusted automatically.
- Attention was verified with isolated tmux statuses and actual adapter event handlers, not a real model-generated OMP question. See the verification record for remaining gaps.
- The embedded terminal supports keyboard input and wheel scrolling, not mouse clicks/dragging, terminal graphics or advanced keyboard protocols. Use `delux attach` for the terminal's full behavior.
- iPhone builds require separate signing. TestFlight/App Store distribution, background notifications, desktop SSH aliases, ProxyJump, imported private keys and keyboard-interactive/MFA are not included.
