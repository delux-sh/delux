# Delux 0.1.0

Delux finds your existing tmux sessions across your computers, previews their screens, and lets you attach without installing a remote Delux service.

## What's included

- Local session discovery, optional Tailscale computer discovery, and explicit SSH hosts or aliases.
- A searchable session list with pinned sessions and screen previews.
- Embedded SSH/tmux attachment in the right-hand panel. Tab focuses the terminal; Shift-Tab returns to the list without disconnecting. Detach with your tmux prefix followed by `d`; sessions keep running after detach or quit.
- Remote username confirmation before sign-in or host-key trust, with SSH configuration support for users, keys, ports, and jump hosts. Delux does not store passwords or private keys.
- `delux list --json` for inventory and `delux attach HOST SESSION` for full-terminal attachment.

## Install

After the separately approved public Homebrew tap is available:

```sh
brew install delux-sh/tap/delux
```

Homebrew installs tmux and, on Linux, OpenSSH. macOS uses its system OpenSSH. If a previous manual installation runs instead, check `command -v delux` and your `PATH`.

Release archives cover these native platforms:

| Platform | Archive |
| --- | --- |
| macOS Apple Silicon | `delux-0.1.0-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `delux-0.1.0-x86_64-apple-darwin.tar.gz` |
| Linux ARM64 | `delux-0.1.0-aarch64-unknown-linux-musl.tar.gz` |
| Linux x86_64 | `delux-0.1.0-x86_64-unknown-linux-musl.tar.gz` |

Download the archive for your platform and `SHA256SUMS` from this release. Compare the archive's `shasum -a 256` output (or `sha256sum` on Linux) with its exact entry in `SHA256SUMS` before extracting and placing `delux` on your `PATH`. Source installation remains available via `cargo install --path . --locked` from the [0.1.0 source](https://github.com/delux-sh/delux/tree/v0.1.0); see the [README](https://github.com/delux-sh/delux/blob/v0.1.0/README.md) for build prerequisites and usage.

Local discovery and attachment need tmux 3.2+. Remote access needs a local OpenSSH client and a remote SSH server, with tmux 3.2+, `base64`, and `tr` available to noninteractive `/bin/sh` commands. Tailscale is optional; use `delux --local` or `delux --host HOST` without it.

## Known limits

- Discovers existing sessions on the default tmux server only; no session creation or custom `tmux -L` / `-S` server discovery.
- Session ages track the last screen-output change, not whether a program is busy or finished.
- The embedded terminal supports keyboard input and mouse-wheel scrolling, but not mouse clicks/dragging, terminal graphics, or advanced keyboard protocols. Use `delux attach` for your terminal's full behavior.
- Selecting a session inside the same local tmux server switches the current client instead of nesting it.
- `delux list` returns available results but exits with status 1 if a computer fails.
